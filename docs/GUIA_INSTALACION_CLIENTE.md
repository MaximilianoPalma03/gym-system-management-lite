# Higea Fitness — Guía rápida de instalación para el cliente

Gracias por elegir Higea Fitness. Esta aplicación administra clientes, planes, cuotas, cobros e informes de tu estudio, de manera local y sin conexión obligatoria a Internet.

## Primera instalación

1. Descargá el APK desde el enlace oficial que te entregó el vendedor.
2. Abrí el archivo descargado en tu Android. Si el sistema solicita permitir instalaciones desde la aplicación con la que abriste el archivo, autorizá únicamente esa fuente si reconocés el APK recibido. Podés desactivar ese permiso al terminar.
3. Abrí **Higea Fitness**. La primera vez verás un código de instalación corto, por ejemplo A4Y3-B7K2.
4. Tocá **Enviar código al vendedor**. Se abrirá WhatsApp con el mensaje listo para confirmar.
5. El vendedor te enviará una licencia para ese código. Copiala y tocá **Pegar licencia** y luego **Activar aplicación**.
6. Configurá en **Ajustes** el nombre, los planes y precios, el color y el logo de tu estudio.

Una vez activada, la licencia sigue funcionando offline en esta instalación mientras se conserven sus datos. Cambiar de celular o borrar los datos puede requerir otra activación.

## Tus datos

Los datos se guardan localmente en tu teléfono y no se sincronizan automáticamente. En Ajustes, elegí **Guardar respaldo cifrado** y guardá una copia fuera del teléfono. Conservá también su contraseña. Recomendamos realizar respaldos periódicos, especialmente antes de cambiar de celular o restaurar información.

## Cómo instalar una actualización

1. Recibí el nuevo APK de Higea Fitness desde el mismo canal de entrega.
2. Abrilo y elegí **Actualizar**; no desinstales la versión anterior.
3. Abrí Higea y comprobá que continúen tus clientes, pagos y preferencias.

Si Android rechaza la actualización, contactá al vendedor y NO borres la aplicación ni sus datos. Las actualizaciones oficiales mantienen la misma identidad y firma Android.

## Asistencia

Usá el mismo WhatsApp desde el que recibiste la activación para consultar dudas o pedir ayuda. Nunca envíes la contraseña de tus respaldos ni información privada de tus clientes por mensajes públicos.
